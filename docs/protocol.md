# Протокол Mega ↔ ESP8266

Mega отправляет конфигурацию ESP8266 строкой:

`CFG|SSID|PASS|HOST|PORT|PATH|POLL_MS`

ESP8266 может запросить конфигурацию строкой `REQCFG`.

Текущий пакет телеметрии совместим с форматом:

`DATA|p|l|g|b|v10|soc|d|a|eta|s|HH:MM|crc`

Mega также подготовлена к расширенному пакету:

`DATA|p|l|g|b|v10|soc|d|a|eta|s|HH:MM|dc|ep|ai|br|bc10|crc`

Где дополнительные поля предназначены для серверного управления длительностью цикла, долей ENERGY, временем экрана автономности, яркостью панели и током АКБ в десятых ампера. CRC — CRC16-CCITT по payload `DATA|...`.
