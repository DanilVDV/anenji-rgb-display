# Архитектура ANENJI RGB Display

## Компоненты

- **Arduino Mega** управляет RGB LED-матрицей 64×32 через библиотеку RGBmatrixPanel.
- **ESP8266** подключается к Wi-Fi, запрашивает данные RMS по HTTP и передаёт короткие UART-пакеты на Mega.
- **RMS/OpenWrt** предоставляет компактный JSON по `/api/rgb` (порт 8088).

## Обмен Mega ↔ ESP8266

UART: `Serial3`, 19200 бод.

Mega отправляет конфигурацию:

```text
CFG|SSID|PASS|HOST|PORT|PATH|POLL_MS
```

ESP8266 может запросить её строкой `REQCFG`.

ESP8266 отправляет телеметрию:

```text
DATA|pv|load|grid|battery|voltage10|soc|discharging|attention|eta|state|HH:MM|crc
```

Контрольная сумма — CRC16-CCITT. Планируемое расширение: `dc|ep|ai|br|bc10` перед CRC.

## Экран

Режим ENERGY показывает потоки PV, сети, нагрузки и батареи. Режим CLOCK показывает часы. При разряде доступен экран AUTONOMY с оставшимся временем работы.

Обновлять только изменившиеся значения: полный сброс матрицы на каждом цикле вызывает мерцание. Нулевые отображаемые значения PV и GRID (`0.0 кВт`) не показывать; неактивные линии серые. В простое АКБ ток скрывать.

## Аппаратные особенности

- Буззер подключён к Mega pin 8.
- Watchdog AVR — 8 секунд.
- Для русских надписей используется внешний U8g2-шрифт.

Точные пины RGBmatrixPanel и схема подключения определяются исходником Mega-прошивки.
