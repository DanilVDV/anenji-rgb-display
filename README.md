# ANENJI RGB Display

Проект информационного RGB-табло 64×32 для системы ANENJI: солнечная генерация, сеть, нагрузка дома, заряд/разряд АКБ, SOC, часы и прогноз автономности.

## Архитектура

- **Arduino Mega 2560** — отрисовка HUB75-панели 64×32, логика экранов, анимации и buzzer.
- **ESP8266** — Wi-Fi/HTTP мост к RMS/OpenWrt и UART-связь с Mega на 19200 бод.
- **RMS/OpenWrt** — API телеметрии `/api/rgb`.

## Актуальная прошивка

`firmware/mega/anenji_rgb_display.ino` — текущая версия Mega.

Ключевое поведение текущей версии: частичная перерисовка без лишнего мерцания; серые линии при отсутствии потока; `0.0` для PV/GRID не показывается, если отображаемая мощность округляется до нуля; ток АКБ скрывается в состоянии idle; экран часов и автономности при разряде; подготовка к серверным настройкам яркости/времени экранов/тока АКБ.

## Безопасность

Пароли Wi-Fi в импортированных версиях удалены и заменены на `<WIFI_PASSWORD>`. Перед прошивкой задайте свои параметры сети локально.
